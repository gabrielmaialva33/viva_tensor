viva_tensor

High-performance tensor library for Gleam/BEAM. Pure Gleam API with optional native acceleration via Intel MKL, CUDA Tensor Cores, cuSPARSELt and CUTLASS.

Gleam 1.16+ OTP 28 CUDA Tensor Cores Intel MKL 2:4 Sparsity

Quickstart

gleam add viva_tensor
import viva_tensor as t

let a = t.zeros([1000, 1000])
let b = t.random_uniform([1000, 1000])
let assert Ok(c) = t.matmul(a, b)
let mean = t.mean(c)

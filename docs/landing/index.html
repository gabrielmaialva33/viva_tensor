viva_tensor

A tensor library for Gleam on the BEAM. Pure-Gleam tensor API with zero-copy views, automatic broadcasting, and an optional native acceleration layer over Intel MKL, cuBLAS / cuBLASLt, cuSPARSELt and CUTLASS.

v2.2.101 Gleam 1.16+ OTP 28 CUDA 13 Intel MKL 2:4 Sparsity Inference API

Quickstart

gleam add viva_tensor
import viva_tensor as t

let a = t.zeros([1000, 1000])
let b = t.random_uniform([1000, 1000])
let assert Ok(c) = t.matmul(a, b)
let mean = t.mean(c)

For quantised inference (FP8 / INT8 2:4 / INT4 2:4 sparse), prepack a weight once and reuse the handle across many forward passes: 

import gleam/option.{None}
import viva_tensor as t

let assert Ok(packed) = t.prepack_fp8_weight(weight)
let assert Ok(output) = t.linear_fp8(input, packed, None)

Native acceleration is optional: pure-BEAM mode works for portability, and the library transparently upgrades to the CUTLASS / cuBLASLt / cuSPARSELt paths once priv/viva_tensor_zig.so is built locally.

Measured throughput (RTX 4090 @ 4096×4096 GEMM)

All numbers are kernel-only via cudaEvent_t, averaged over 30 iterations after one warm-up. See RESULTS.md for full methodology.

  • cuBLASLt FP16 (algo-sweep): 266 TFLOPS
  • CUTLASS FP8 + FP16 accum: 392 TFLOPS (vs PyTorch FP8 _scaled_mm 308)
  • cuSPARSELt INT8 2:4: 629 TFLOPS
  • CUTLASS INT4 2:4: 1074 TFLOPS (no PyTorch equivalent today)
